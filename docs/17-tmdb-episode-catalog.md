# 电视剧按 TMDB 选集

媒体库详情页与 TMDB 详情页共用选集卡片。TMDB 提供季号、集号、标题、剧照及播出日期；所有已提供的集数都可选择，包括未播出的集。日期只用于标注，实际能否播放由服务器的 PlaybackInfo 决定。

- 未来日期标注“未播出”和预计播出日期；已入库的超前资源仍可播放。选中状态用勾选图标表示，不覆盖未播出标记。
- 日期缺失显示“播出日期待定”，不会因此禁止播放。
- 选择一集后，按同一部剧的季号、集号查询版本；再按一次选中的卡片播放。缺集显示明确的集号提示并禁用播放按钮，不会改播默认的下一集。
- 当前媒体库来源始终参与，其他来源遵循聚合搜索设置；当前来源关闭聚合时，也能播放自己的剧集。各来源的全集查询共用 provider，避免当前来源被搜索再次找到后重复获取。
- 默认选集沿用服务器下一集 / 已有观看进度；手动选择季、集后，异步加载不会用默认进度覆盖它。换季清除原来的资源选择。
- TMDB 尚未收录、而服务器已入库的季与集仍会补充保留。TMDB 季接口失败或返回空数据时使用服务器的标题、日期与剧照。没有配置 TMDB、条目没有 TMDB ID、或剧集详情不可用时，保留原服务器选集方式。

资源匹配要求服务器与 TMDB 的季号、集号一致。播出日期只是日历信息，不用来判断资源是否存在。没有可靠日期时也不推断已经播出。

测试：`test/episode_catalog_test.dart` 覆盖两个详情入口、超前集跨服务器播放、无资源缺集、同集号不同季、遥控器确认、换季、全集请求复用和 TMDB 失败回退。PR Checks 使用发布所用 Flutter 版本运行静态检查和全套测试。
