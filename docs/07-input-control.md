# 07 · 操控方案

设计参考：Android TV / Google TV 系统规范（Leanback）、Netflix / YouTube TV、Kodi、Jellyfin Android TV、Windows 上的 PotPlayer / mpv / YouTube 网页快捷键。原则是**用户不看说明也能用**：方向键移动、确认键执行、返回键后退永远成立；高级功能放在菜单键和长按上。

## 0. 两个平台的操作方式（不要混用）

代码里统一由 `lib/app/platform_profile.dart` 的 `PlatformProfile`（`tv` / `desktop`）判断，页面里不直接写平台判断。

| 场景 | Android TV（遥控器） | Windows（键盘 + 鼠标） |
| --- | --- | --- |
| 返回上一层 | 遥控器返回键 | 标题栏左上角返回按钮、鼠标侧键（后退）、Esc、Backspace、Alt+← |
| 首页再按返回 | 不退出，提示「长按返回键 3 秒可以退出」；长按返回 3 秒弹出退出确认（默认焦点在「取消」） | 不退出（关闭窗口才退出） |
| 窗口 | 全屏，无窗口按钮 | 沉浸式标题栏：顶部可拖动、双击最大化、最小化 / 最大化 / 关闭按钮，F11 全屏 |
| 选中 / 高亮 | 方向键移动焦点，页面跟随滚动（关键线滚动） | 鼠标悬停高亮，**页面不动**；滚轮上下滚动，按住左键拖动左右滚动；方向键也可用 |
| 执行 | OK 键 | 单击 / Enter |
| 菜单 | 菜单键 / 长按 OK | 右键 / 菜单键 / Shift+F10 |
| 文本输入 | OK 弹出系统输入法；搜索页用屏幕字母键盘（支持拼音首字母） | 物理键盘直接输入，不显示屏幕键盘 |
| 播放器 | OK 暂停、←→ 快进退、↓ 菜单、返回键退出 | 空格暂停、←→ / J L 快进退、OSD 左上角返回按钮、Esc 退出、F11 全屏 |
| 播放内核 | ExoPlayer（失败回退 mpv），可在设置里改 | 固定 mpv |
| 设置项 | 播放内核、自动帧率、隧道播放（仅 TV） | 无这些选项 |

## 1. 统一按键语义

所有输入先映射为同一组**意图（Intent）**，页面只处理意图，不直接处理按键。

| 意图 | 遥控器 | 键盘 | 鼠标 | 手柄 |

| 确认 | OK（DPAD_CENTER / ENTER） | Enter | 左键单击 | A |

## 2. 浏览页（首页、详情、资源库、搜索）

### 2.1 遥控器

| 按键 | 行为 |
| --- | --- |
| ← → | 行内移动；行首按 ← 进入导航栏 |
| ↑ ↓ | 在行之间移动，**恢复该行上次的焦点位置**（每行独立记忆，参考 Netflix） |
| 长按方向键 | 连续移动，初始 5 次/秒，持续 1 秒后加速到 12 次/秒；行滚动使用"跟随动画"而不是逐次动画，避免卡顿 |
| OK | 打开 / 执行 |
| 长按 OK / 菜单键 | 上下文菜单（标记已看、加入收藏、移出继续观看、去详情、选择资源播放） |
| 返回 | 行内已滚动 → 先回到行首；已在首页顶部 → 回到 Hero；Hero 上再按 → 提示长按退出；按住返回键不会连续返回；Android 系统的返回请求（返回手势等）也按应用内返回处理，不会直接关闭应用 |
| 播放键 | 在卡片上直接播放（跳过详情，使用默认资源） |
| 频道 +/- | 网格页整页翻页 |

### 2.2 焦点规则

- **行内滚动**：焦点卡片固定在行的左侧关键线（距安全区 0 ~ 1 张卡的位置），行内容滚动，焦点不跑到屏幕右边缘（Leanback 关键线滚动）。
- **纵向滚动**：焦点行固定在屏幕上方约 1/3 处，页面滚动。
- **跨区域**：从一个区域移到另一个区域时，选择几何上最近的元素；但"行→行"使用行记忆优先。
- **页面返回**：返回上一页时恢复离开时的焦点元素。
- **数据刷新不抢焦点**：行数据异步加载完成、Hero 轮播切换时，不改变当前焦点。
- **焦点永不丢失**：焦点元素被移除时，焦点转到同一行的相邻元素，否则转到上一行。

### 2.3 键盘与鼠标（Windows）

| 操作 | 行为 |
| --- | --- |
| 方向键 / Enter / Esc | 与遥控器一致（键盘用户可以完全不用鼠标） |
| 鼠标悬停 | 设置焦点（放大效果一致）；背景切换加 300ms 防抖，避免鼠标快速划过时背景频繁闪烁 |
| 滚轮 | 页面纵向滚动；在行上按住 Shift 滚动或悬停时显示行两端的 ‹ › 按钮横向翻页 |
| 单击 | 打开；单击海报上的 ▶ 小按钮（悬停出现）直接播放 |
| 右键 | 上下文菜单 |
| 鼠标侧键后退 / Alt+← | 返回 |
| F11 | 全屏切换 |
| Ctrl+F 或 `/` | 打开搜索并聚焦输入框，直接打字 |

鼠标模式与键盘模式自动切换：一旦有方向键输入，隐藏鼠标指针和悬停按钮；鼠标移动后恢复。

## 3. 播放页

### 3.1 遥控器 —— OSD 隐藏时（全屏观看）

| 按键 | 行为 |
| --- | --- |
| OK | 暂停 / 继续，同时显示 OSD（Netflix / YouTube TV 一致） |
| ← / → | 快退 / 快进 10 秒（可设置 5/10/15/30）；连续按累加，屏幕中央显示 `+30s`，停止按键 0.8 秒后才执行 seek（避免多次缓冲） |
| 长按 ← / → | 进入**拖动模式**：显示进度条与缩略图预览，速度随按住时长递增（×2 → ×8 → ×32），松开后停在当前位置，再按 OK 确认跳转，按返回取消 |
| ↑ | 显示 OSD，焦点在进度条上 |
| ↓ | 打开底部"选集 / 资源"面板 |
| 菜单键 | 打开右侧设置面板（资源、音轨、字幕、速度、画面比例、片头片尾） |
| 返回 | 退出播放（进度已保存）；若有面板/OSD 打开则先关闭面板 |
| 播放暂停 / 快进快退媒体键 | 对应功能 |
| 上一曲 / 下一曲、频道 -/+ | 上一集 / 下一集 |
| 数字 1~9 | 跳转到 10% ~ 90%（可在设置中关闭） |

### 3.2 遥控器 —— OSD 显示时

```
┌──────────────────────────────────────────────────────────────────┐
│ 时光代理人  第1季 第1集 EMMA                       21:35  🔋 ChaPanda│
│                                                                  │
│                                                                  │
│                                              ┌──────────────┐    │
│                                              │ 跳过片头  ⏭  │    │
│                                              └──────────────┘    │
│ ▶  ━━━━━━━━━━━━━━●─────────────────────────────  08:12 / 22:04    │
│    [⏮ 上一集] [⏭ 下一集] [选集] [资源 4K HDR10] [音轨] [字幕] [⚙] │
└──────────────────────────────────────────────────────────────────┘
```

- 焦点默认在进度条：← → 按 10 秒步进拖动（带缩略图预览），OK 确认跳转并播放。
- ↓ 进入按钮行，← → 选择，OK 打开对应面板。
- 无操作 5 秒自动隐藏 OSD。
- 进度条缩略图来源：Emby/Jellyfin Trickplay / BIF、Plex BIF；没有时只显示时间。

### 3.3 跳过片头 / 片尾按钮的焦点规则

- 进入片头区间时，右下角出现"跳过片头"按钮并**自动获得焦点**，持续显示到片头结束（若 OSD 隐藏，10 秒后按钮缩小为半透明，但焦点仍在）。
- 按钮可见时 **OK = 跳过**（而不是暂停），这是用户最直觉的操作；按其他方向键则按钮失焦，回到普通 OSD 行为。
- 片尾：出现"下一集"卡片（下一集缩略图 + 倒计时圆环）。OK = 立即播放下一集，返回 = 取消并继续看片尾。自动模式下倒计时结束自动下一集。
- 连续自动播放 3 集无任何按键时，弹出"还在观看吗？"（可关闭）。

### 3.4 侧边面板

面板从右侧滑入，宽 560，列表式；↑↓ 选择，OK 确认，← 或返回关闭。面板打开时视频继续播放（选资源时除外）。

## 4. 文本输入

| 平台 | 方案 |
| --- | --- |
| Android TV | 自绘屏幕键盘（拼音首字母、全字母、数字符号三种布局）+ 系统语音输入；服务器地址等长文本额外提供**手机扫码输入**（TV 起局域网网页，后续版本） |

## 5. 实现要点（Flutter）

- `app/input/intent_mapper.dart`：`Shortcuts` 把 `LogicalKeyboardKey.arrowUp/select/enter/gameButtonA/goBack/escape/contextMenu/mediaPlayPause/...` 统一映射到自定义 `Intent`；长按通过 `KeyRepeatEvent` 计时识别。
- Android 端在 `MainActivity` 中补充映射 Flutter 未覆盖的 KeyCode（如 `KEYCODE_MENU`、`KEYCODE_CHANNEL_UP/DOWN`、`KEYCODE_INFO`、部分国产遥控器的自定义键）并通过 MethodChannel 下发。
- 播放器使用 PlatformView（ExoPlayer）时，按键必须由 Flutter 侧接收，原生 View 设置 `focusable=false`，防止原生 View 抢焦点导致遥控器失灵。
- `ui/focus/`：
  - `FocusableCard`：焦点动画、悬停转焦点、长按菜单。
  - `FocusMemory`：按 `rowId` 记录行内索引，按路由记录页面焦点。
  - `KeylineScrollController`：行内/纵向关键线滚动，长按连续移动时节流。
- Android Manifest：`android.software.leanback`（required=false）、`android.hardware.touchscreen`（required=false）、`LEANBACK_LAUNCHER` 入口 + 320×180 banner。
