# 06 · 大屏 UI 设计

## 1. 从 Rex（iOS 竖屏）到大屏的转换原则

| Rex（手机） | Viora（电视 / PC） |
| --- | --- |
| 竖屏纵向长滚动 | 横屏：**纵向是行，行内横向滚动**；每次只聚焦一个元素 |
| 底部 Tab 栏 | **左侧导航栏**（收起只显示图标，焦点进入时展开） |
| 点击 | 焦点 + 确认；焦点态必须一眼可见（放大 + 描边 + 阴影） |
| 背景固定 | **动态背景**：焦点移到哪张卡，页面背景就淡入它的背景图（参考 Apple TV / Google TV） |
| 毛玻璃浅色主题 | 默认**深色主题**（大屏环境光暗，浅色刺眼）；保留浅色主题可选 |
| 信息密度高 | 字更大、每行可见卡片更少、关键信息前置 |

## 2. 设计规范

基准画布 **1920 × 1080**（Flutter 中按 `dp = 实际宽 / 1920 × 1920` 统一缩放，Windows 窗口任意尺寸都等比适配；窗口很窄时行内卡片数减少而不是缩小字号）。

| 项 | 规范 |
| --- | --- |
| 安全区 | 左右 96，上下 54（≈5% 过扫描），所有可聚焦元素必须在安全区内 |
| 字号 | 大标题 48 / 页面标题 36 / 行标题 28 / 正文 24 / 辅助 20；最小不低于 20 |
| 竖版海报卡 | 220 × 330，间距 24，一行可见约 7 张 |
| 横版卡（继续观看 / 剧集） | 400 × 225，一行约 4 张 |
| 人物卡 | 圆形 160，名字在下 |
| 平台 / 公司 Logo 卡 | 300 × 170 |
| 焦点态 | 放大 1.08（150ms ease-out）、3px 白色描边、外发光阴影、标题文字由灰变白；仅聚焦卡片显示副标题 |
| 圆角 | 卡片 16，按钮 999（胶囊），面板 24 |
| 颜色（深色） | 背景 `#0E0F13`；表面 `#1A1C22` / 60% 透明；主色取自当前背景图主色（Palette 提取），回落 `#7C8CFF`；文字 `#FFFFFF` / 70% / 45% |
| 动效 | 背景交叉淡入 400ms；行滚动 250ms；全部可在设置中"减少动效" |
| 图片 | 根据卡片尺寸请求 `maxWidth`（海报 440、背景 1920），预加载焦点前后各 3 张 |

## 2.1 视觉质感：磨砂玻璃与性能

整体风格：**深色 + 磨砂玻璃（Glassmorphism）+ 内容图片主导**。Flutter 用 Impeller 渲染，可以实现：

| 效果 | Flutter 实现 |
| --- | --- |
| 实时磨砂玻璃（导航栏、侧边面板、OSD、焦点信息区） | `BackdropFilter(ImageFilter.blur)` + 半透明填充 + 1px 高光描边 + 细噪点纹理 |
| 大面积模糊背景（页面底图） | **预模糊**：背景图解码时用 `ImageFilter.blur` 离屏渲染一次并缓存，之后只做交叉淡入，不做逐帧实时模糊 |
| 氛围光 / 主题色 | 从当前背景图提取主色（`palette_generator`），生成径向渐变光斑叠在背景上 |
| 焦点发光、高光扫过 | 自定义 `FragmentShader`（GLSL）或渐变动画 |
| 立体海报 / 视差 | `Transform` 3D 透视 + 焦点时轻微倾斜（Windows 鼠标跟随） |

性能分级（低端电视盒子 GPU 弱，实时模糊是最贵的效果）：

| 档位 | 判定 | 策略 |
| --- | --- | --- |
| 高 | Windows、近年中高端 TV（如 NVIDIA Shield、新款 Google TV） | 全部实时模糊 |
| 中 | 默认 | 面板/OSD 实时模糊（面积小），页面背景用预模糊 |
| 低 | 启动时测帧耗时，或用户在设置中选择"性能优先" | 不做实时模糊，用不透明度更高的深色半透明面板替代，视觉接近 |

## 2.2 分辨率适配与窗口缩放（v0.7.1）

- 所有界面在 1920 宽的设计画布上布局，再按屏幕 / 窗口等比缩放；绘制按设备实际分辨率进行（4K 电视上文字、图标、边框都是原生清晰度，不是放大的位图）。
- 图片按实际物理像素取图和解码（`lib/ui/widgets/image_sizing.dart`）：设计宽度 × 每设计像素对应的物理像素，按 128px 向上取整。
  - 媒体服务器图片：请求 `maxWidth` = 该值，并以该宽度解码（`cacheWidth`），减少内存占用。
  - TMDB：选不小于该值的最小尺寸（海报 1080P 用 w342 → 4K 用 w500；全屏背景 1080P 用 w1280 → 4K 用原图）。
- Windows 拖动窗口边框：连续调整大小期间冻结界面布局，只缩放上一帧的界面快照（`SnapshotWidget`）；停止拖动 160ms 后按新尺寸重新布局一次。最大化 / 还原 / 全屏等一次性变化直接重新布局。播放页不用快照（视频要实时更新），只冻结布局。

│ 🔍 │                                                               │
│ 🏠 │                      页面内容                                  │
│ 🗄 │                                                               │
│ ♥  │                                                               │
│ 🕘 │                                                               │

- TV：在内容最左一列按 ← 进入导航栏；在导航栏按 → 或返回键回到内容。焦点离开导航栏 3 秒后导航栏滑出屏幕隐藏，按 ← 进入时滑回。
- Windows：鼠标离开导航栏 3 秒后隐藏；鼠标移到窗口最左侧边缘时滑回；键盘焦点在导航栏上时不隐藏。

```
┌────┬───────────────────────────────────────────────────────────────┐

│    │   [▶ 播放]  [ⓘ 详情]  [♡]                  ● ● ○ ○ ○ ○ ○ ○     │
│    │                                                               │
│    │ 继续观看                                                       │
│    │ ┌────────┐┌────────┐┌────────┐┌────────┐                       │
│    │ │ 横版图  ││        ││        ││        │  进度条 + "S1E3 · 剩 12 分"│
│    │ └────────┘└────────┘└────────┘└────────┘                       │

└────┴───────────────────────────────────────────────────────────────┘
```

- Hero 占屏幕上半部分（约 60%），焦点初始落在"播放"按钮上。焦点停在 Hero 按钮上 8 秒无操作时自动轮播到下一部（每次按键重新计时），焦点离开 Hero 后停止轮播；← → 在按钮间移动，最左侧再按 ← 进入导航栏。
- 焦点向下进入行后，Hero 收缩为背景，**背景跟随焦点卡片切换**，顶部显示焦点卡片的标题、年份、评分、简介一行（"焦点信息区"）。
- 行顺序：继续观看 → 正在热映 → 正在播出 → 本周趋势 → 今日动漫 → 热门人物 → 播出平台 → 分类浏览 → 高分剧集 → 电影公司 → 各服务器最近入库。
- 卡片角标：无资源的 TMDB 条目卡片半透明 + "无资源"小标签（可设置为隐藏）；有多个资源显示数量。
- 继续观看卡片长按 / 菜单键：从继续观看移除、标记已看、去详情。

- 首屏只放"决定看不看"所需的信息和操作按钮；其余内容向下滚动。焦点从按钮行向下，页面整体上滚，背景保留。
- "播放"按钮文案随状态变化：未看 → `播放 第1季·第1集`；看到一半 → `继续 第1季·第3集 · 剩 12 分`；电影 → `播放` / `从 35:12 继续`（再提供"从头播放"）。
- "资源"按钮显示当前默认版本摘要，按下直接打开版本选择面板（与下方"播放资源"区同一数据），方便不往下滚就换版本。
- 剧集卡片聚焦时，"播放资源"区自动切换为该集的资源。
- 季切换：横向 Tab；季很多（如 >10）时改为按 OK 弹出季列表。
- "⋯"菜单：标记整季已看、刷新元数据、手动匹配（拆分/合并作品）、片头片尾设置（本剧）。
- 演职员卡片 → 人物页（TMDB 人物作品，标出有资源的）。

- 卡片信息与 Rex 一致：图标、名称、最近访问、在线状态点、备注（线路名 / 到期信息）、电影与剧集数量、R18 标签。
- 卡片菜单（菜单键 / 右键 / 长按 OK）：切换线路、测速、编辑、绑定代理、设置播放 UA、重新同步索引、删除。
- 进入服务器 → 媒体库列表（横向大卡）→ 媒体库网格（海报网格，顶部筛选：排序 / 类型 / 年份 / 已看未看，右侧 A-Z 快速索引，遥控器上可用"频道+/-"翻页）。
- "编辑"模式：拖拽排序（TV 上按 OK 拿起，方向键移动，再按 OK 放下）、批量删除。
- R18 服务器在设置开启"隐藏成人内容"时不出现在首页、搜索和资源库（需 PIN 解锁显示）。

## 9. 设置

左侧分类、右侧内容的两栏布局：

| 分类 | 内容 |
| --- | --- |
| 服务器与线路 | 服务器列表、线路、测速、自动选线 |
