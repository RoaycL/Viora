# 10 弹幕

参考 ForwardWidgets 的 `danmu_api` 弹幕模块（含多源并发版），对接自部署的
[huangxd-/danmu_api](https://github.com/huangxd-/danmu_api)（弹弹play 兼容接口，聚合腾讯、爱奇艺、优酷、B 站、人人等）。

## 1. 服务器

- 设置 → 弹幕，最多 3 个服务器，地址格式 `https://{域名}/{token}`；局域网如 `http://192.168.1.10:9321/87654321`
  （没写协议时：IP / 无点主机名补 `http`，域名补 `https`）。
- 保存时用空关键词搜索做连接测试：401 / 403 提示 token 不对，404 提示地址不对。
- 多个服务器并发搜索，结果按 `animeId` 去重，每个作品记住来自哪个服务器，后续取集列表、弹幕都用那个服务器。

## 2. 接口

| 用途 | 接口 |
| --- | --- |
| 自动匹配 | `POST /api/v2/match`，`{"fileName": "凡人修仙传 S01E02"}` → `isMatched`、`matches[0].episodeId` |
| 搜索作品 | `GET /api/v2/search/anime?keyword=` → `animes[]`（animeId / animeTitle / type / episodeCount） |
| 集列表 | `GET /api/v2/bangumi/{animeId}` → `bangumi.episodes[]`（episodeId / episodeTitle / episodeNumber） |
| 弹幕 | `GET /api/v2/comment/{episodeId}?withRelated=true&chConvert=0&format=json` → `comments[]`（`p` = `时间,模式,颜色,…`，`m` = 内容） |

`p` 有 8 段以上时是 B 站格式（`时间,模式,字号,颜色,…`），颜色取第 4 段。模式 4 = 底部、5 = 顶部，其余按滚动处理。

## 3. 匹配顺序（`resolveDanmaku`）

1. 这部剧这一季（电影按条目）记住的手动选择：作品 + 集数偏移，取「本地集数 + 偏移」那一集。
2. 服务器自动匹配：`剧名 S01E02`（电影只用片名）。返回 0 条时继续往下。
3. 按剧名搜索，按 `matchSeason` 排序（标题以剧名开头，剩余部分为空 = 第 1 季，或含阿拉伯 / 中文数字等于季号），
   取标题以剧名开头的第一个，再按集数选集（先比 `episodeNumber`，再按顺序）。

手动选择（播放菜单 → 弹幕 → 搜索并选择 / 按关键词搜索）选中某一集后，记录
`偏移 = 弹幕源集数 − 本地集数`，同一季后面的集自动沿用。时间偏移（提前 / 延后）也按剧 + 季记住。

## 4. 过滤

和多源版脚本一致，在客户端处理（原始弹幕缓存最近 4 集，改设置不用重新下载）：

- 繁简转换：保持 / 转简体 / 转繁体（lpinyin）。
- 弹幕内容屏蔽词、搜索结果屏蔽词（逗号分隔）。
- 数量上限 1000 / 3000（默认）/ 5000 / 不限：超出时随机抽取后按时间重排，全片密度等比例降低。
- 颜色：保持 / 全部纯白 / 部分彩色（50%）/ 全部彩色，调色板与脚本相同。
- 服务器偶尔抓取源站失败返回 0 条：不缓存，按"没有匹配到"处理，可在菜单里重新匹配。

## 5. 渲染（`DanmakuLayer`）

- 盖在视频上、OSD 下面，不接收点击。Ticker 每帧推进，CustomPainter 绘制；文字描边（深色文字用白色描边）。
- 位置按视频时间计算：内核约 250ms 报一次进度，中间按速率插值，小误差每次修正 20%；
  误差超过 1 秒（拖动进度、切换资源）清屏并二分查找新位置。暂停时停住，倍速时一起变快。
- 滚动弹幕分行：新弹幕放进第一条"不会追上前一条"的行（长的走得快，按两端点检查），没有空行就丢弃，不叠在一起。
  显示区域 1/4 / 半屏（默认）/ 3/4 / 全屏；速度 = 走完屏幕 12 / 9 / 6 秒。
- 顶部 / 底部弹幕居中停留 4 秒，可在设置里关闭。
- 卡顿后积压超过 0.8 秒的旧弹幕直接跳过，一帧最多出 12 条。

## 6. 操作

| | Windows | Android TV |
| --- | --- | --- |
| 开关弹幕 | `D` 键，或 OSD 上的「弹幕 开 / 关」按钮 | ↓ / 菜单键 → 弹幕 → 隐藏 / 显示 |
| 手动选择 | 右键 / 双击 → 弹幕 → 搜索并选择 | ↓ / 菜单键 → 弹幕 → 搜索并选择 |
| 时间偏移 | 菜单 → 弹幕 → 时间偏移 | 同左 |
| 显示区域 / 字号 / 不透明度 / 速度 | 菜单 → 弹幕（或右键「弹」图标）→ 选一项，立即作用在屏幕上的弹幕，并保存到设置 | 菜单键 → 弹幕，或长按「弹」图标 |
| 状态 | `I` 媒体信息里显示条数和来源 | 菜单 → 媒体信息 |

菜单项多（如几十集的集列表）时可以滚动，遥控器移动焦点会自动滚到可见位置。

## 8. 播放中调整样式

播放菜单 → 弹幕里可以直接改显示区域、字号、不透明度、速度，和「设置 → 弹幕」是同一份设置（改了两边同步）。
屏幕上已有的弹幕就地更新、不清屏：字号 / 不透明度变化时重新排版文字；速度变化时按每条已经走过的比例换算起点，位置不跳；
显示区域或字号变化后超出可用行数的弹幕去掉。
