# 11 局域网同步配置

电视上用遥控器输入服务器地址、密码、各种 Key 很麻烦。电视在局域网里临时开一个接收入口，
用手机网页或 Windows 版 Viora 把配置推过去。

## 1. 流程

1. 电视：设置 → 同步配置 → 接收配置。在 8090（被占用时用 8091–8093）端口开一个 HTTP 入口，
   屏幕上显示二维码（`http://<电视IP>:<端口>/?code=<配对码>`）、地址和 4 位配对码。
2. 手机扫码打开配置网页（电视直接提供，不依赖外部资源），填写服务器（可多台、多线路）、
   反向代理、播放 UA、TMDB Key、外部评分凭据、弹幕服务器、片头片尾 Key，点「发送到电视」。可以多次提交。
3. 或者 Windows：设置 → 同步配置 → 发送到电视。扫描本机所在网段（/24，每个地址只试 8090，64 路并发，约 2–4 秒）
   找到开着接收入口的电视；没找到时手动输入电视上显示的地址。输入配对码，勾选要发送的部分后发送。
4. 电视收到后合并配置，并在后台对新增 / 修改的服务器测速、登录、同步索引；窗口里显示进度。

## 2. 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 手机配置网页 |
| GET | `/viora/ping` | `{"app":"viora","name":"Viora · 客厅电视","version":"0.11.2"}`，Windows 扫描用 |
| POST | `/viora/import` | `{"code":"4827","payload":{…}}`，返回 `{"ok":true,"message":"已导入：…"}` 或 `{"error":"…"}` |

`payload` 格式见 `lib/data/sync/config_payload.dart`：`servers`、`proxy`、`playback`、`tmdb`、`danmaku`、`segments`、`ratings` 都可以省略。

## 3. 合并规则

- 服务器按「类型 + 用户名 + 任一线路地址相同」对上的更新（线路整体替换，密码变了清掉旧令牌重新登录），其余新增。
- 不传登录令牌：令牌和设备绑定，电视用账号密码重新登录。
- 反向代理、播放 UA、TMDB、弹幕只覆盖带过来的字段（手机网页只填几项也不会清掉其他设置）。
- 弹幕只同步弹幕服务器、屏蔽词、搜索屏蔽词、繁简转换、颜色设置（`DanmakuConfig.syncedKeys`）；
  每集上限、字号、透明度、显示区域、速度、顶部 / 底部弹幕、默认开启这些显示设置跟屏幕和性能有关，每台设备各自设置，
  收到旧版本发来的完整设置时也只取共用字段。
- 片头片尾：带了 Key 的数据源同时打开；Windows 发来的完整设置覆盖本机设置，Key 存进系统密钥库。

## 4. 安全

- 只在「接收配置」窗口打开期间监听；关闭窗口、5 分钟没有请求都会停止。
- 必须带正确的 4 位配对码（每次随机）；连续输错 5 次更换配对码。
- 只在局域网内直接传输，不经过外部服务器；HTTP 明文，不要在公共 Wi-Fi 下使用。
- 请求体最大 512 KB。

## 5. WebDAV 同步

设置 → 同步配置 → WebDAV 同步：多台设备共用 WebDAV 上的一个配置文件（默认 `Viora/viora-config.json`），坚果云、群晖、Alist 等都可以。

- **内容**：与局域网同步 / 备份同一格式（服务器、反向代理、播放 UA、TMDB、弹幕、片头片尾），外加版本号 `rev` 和 `updatedAt`。
  播放内核、缓冲、家长控制等跟设备有关的设置不同步；WebDAV 自己的设置也不上传。
- **加密（可选）**：填了加密口令时文件内容为 `{"viora":1,"encrypted":{...}}`，PBKDF2-SHA256（6 万次）派生密钥 + AES-256-GCM；
  所有设备填同一个口令，口令不对会提示无法解密。WebDAV 密码和口令存进系统密钥库。
- **判断方向**：本机记下上次同步时的配置摘要（SHA-1，不含来源和版本号）和云端 `rev`：
  - 只有本机改了 → 上传；只有云端改了 → 下载，并删除云端没有的服务器（删除也能同步）；
  - 两边都改了（含第一次同步） → 合并（不删除任何一边的服务器）后上传；都没改 → 不动。
  - 也可以手动「用本机覆盖云端」「用云端覆盖本机」。
- **总开关**：WebDAV 同步一栏右侧的开关，关闭后自动、手动都不再同步，地址 / 账号 / 口令保留；重新打开时按记录的状态判断两边谁改过（不当作第一次同步）。
- **自动同步**（默认开）：启动 3 秒后同步一次；配置变化 8 秒后，如果内容摘要变了就同步。换了 WebDAV 地址 / 文件 / 口令时按第一次同步处理。
- **电视**：手机扫码网页和 Windows「发送到电视」都可以带上 WebDAV 设置，电视收到后马上从 WebDAV 下载其余配置。
- 测试：`test/sync/webdav_sync_test.dart`（内存 WebDAV 服务器 + 两台设备：上传、合并、下载、删除同步、加密、口令 / 账号错误、密钥库）。

## 6. 测试

- `test/sync/receive_dialog_test.dart`：接收窗口开启 / 关闭。

## 外部评分

评分来源开关、顺序和 API 地址支持同步；在「设置 → 元数据」开启「同步评分凭据」后才导出自行填写的 OMDb Key / Trakt Client ID。接收端不会自动开启凭据导出；未传 Key 保留本机值，显式空 Key 清除。评分缓存不同步。手机网页可直接填两个凭据，接收后开启相应来源。
