# 首页 2B：首屏、轮播与输入连续性

日期：2026-10-15。基线：main `6d2f217` / v0.15.13+37。工作分支：`codex/home-hero-interaction`。

## 问题与调整

此前 Hero 按 72% 视口高度展示，没有为继续观看留出空间；轮播每秒检查计时，聚焦或悬停时仍可能换作品。轮播先换标题、稍后更新背景，慢图会进一步拉长信息错配的时间。桌面只有封面可聚焦时也缺少明确操作反馈。

- **首屏**：有继续观看时按其整行高度预留空间；Hero 默认占比调整为 68%，保留内容最小高度，并随字体放大增加高度。720p/1080p TV 的默认字号用例可完整展示续播卡片。大字或超宽短窗口以可读性优先，允许向下滚动。
- **信息层级**：紧凑首屏使用较短间距和较小标题/Logo 区，元信息允许换行。Logo 回退文字继承同一标题样式，避免其字号与容器不一致；Windows 增加可聚焦的主操作，封面点击仍可进入详情。
- **轮播**：统一为离开操作区后等待 8 秒。焦点、鼠标悬停、拖动、屏外/详情遮挡、后台或系统减少动画时暂停；不再每秒轮询。提供上一部、下一部与暂停/开启控件，鼠标有文字提示，遥控器可逐个到达。手动暂停保存在页面，Hero 被虚拟列表回收后仍保留。
- **背景与操作**：焦点停稳后先准备目标图片，再同时提交标题、背景和操作目标。准备期间保留旧的一组内容；失败或 4 秒未就绪时提交新作品的占位背景。快速连续选择按最新目标累加，旧图片迟到不能覆盖新目标。
- **任务清理**：切换目标、进入详情、账号/客户端改变、列表刷新或页面销毁时取消旧订阅和超时计时器；已显示的同一作品不重复提交。Hero 列表重排按作品 ID 保留当前选择，删除后回落到有效项。
- **减少动画**：Hero 标题过渡与背景切换读取共享动效策略；自动轮播关闭，手动前后切换仍可用。标题只保留最新出场/退场条目，退场信息排除重复朗读，TV 背景继续保持最多两层。

## Windows 滚轮核实结果

Flutter SDK 本身已有 Shift+竖向滚轮映射横轴和横向指针输入的支持，之前的审查不应将其描述为完全缺失。本批复用其事件解析，只为首页启用行边界转交：

| 输入 | 行内可滚动时 | 行到边界时 |
| --- | --- | --- |
| 普通竖向滚轮 | 滚动页面 | 滚动页面 |
| Shift+竖向滚轮 | 滚动当前横排一次 | 交给纵向页面继续浏览 |
| 原生横向输入 | 滚动当前横排 | 保持横排边界 |

边界处理使用同一个 pointer signal resolver，避免同时滚动横排与页面；默认关闭，只有首页使用。系统触控板的实际驱动行为仍需 Windows 实机检查。

## 设计依据与性能边界

继续使用已安装 UI/UX Pro Max 与 Motion Design，选择克制的内容主导方向。UX 检索命中自动轮播的暂停、焦点/悬停停止与减少动画规则；Flutter 检索未命中专门的轮播实现，后续较宽查询只有通用资源释放建议，具体输入 API 按安装 SDK 源码核实。SwiftUI Skill 仅参考稳定状态和可访问性原则，不移植 Apple 平台 API 或交互语义。

没有增加环境动画、全屏模糊或图片包。既有两行后台数据任务、一个下一行图片预取任务、160 设计像素纵向构建缓存、横排虚拟列表、图片下载并发与 TV 图像缓存限制继续回归验证。图片准备复用实际显示的 provider/解码尺寸，并在新目标到来时移除旧监听。

## 验证
