# 详情页交互：季选择、简介与资源入口

本批基于 main `6d2f217`（v0.15.13+37），分支 `codex/detail-interaction`。与首页 2B 的 PR #31 独立，不提升版本号、不自动合并或发布。

## 解决的问题

两个详情入口原来把所有季放在不滚动的 Row 中，30 季会溢出；简介截断后没有完整阅读入口；更换资源必须向下翻找。首屏使用固定高度并向上延伸内容，长标题、放大文字可能画到视口外。

- 两个入口复用 `SeasonSelector`：不超过 6 季保持直接点击/确认切换，横向受约束并随键盘焦点滚动；更多季使用按需构建的列表面板，打开后定位当前季。保留特别篇和既有排序，不按日期过滤。面板取消不提交，选择后回到触发按钮；账号切换替换选择器后丢弃旧面板结果。
- “完整简介”在独立的纯色面板阅读，鼠标滚轮或遥控器上下可滚动；左右到关闭按钮，从关闭按钮返回保留阅读位置。Esc、遥控器返回、关闭按钮与点击遮罩均可退出。面板不做背景模糊，遵循减少动效；关闭过程不能再次出栈。
- “选择资源”滚动到原有 `SourcesSection`，露出并聚焦当前版本所在分组/卡片。等待布局时如用户已移动焦点或离开路由，取消焦点提交。这个动作不调用播放、选源或额外搜索。加载/无资源状态也有焦点锚点；单清晰度仍显示分组，以保留从加载锚点到结果的导航连续性。
- 首屏采用最小高度与正常内容流，长内容向下增高。操作行可横向滚动；常规首屏返回顶部，大字体导致首屏增高时优先保证操作按钮可见。TMDB Logo 加载/失败时显示文字标题，保留字体回退。
- 两种详情等待元数据时显示相同静态骨架与返回操作。资源区原有循环呼吸动画改成静态卡片，没有循环 ticker，也不为占位发图片请求。

继续使用 DetailLayout、EpisodeCatalogRow、现有 provider、选源键、预热与播放路由。保留 TMDB 未播出日期、服务器独有集数、超前资源、缺集不误播下一集及账号作用域。没有改播放内核、业务数据结构或媒体源存取规则。共享海报转场不在本批实现。

## 验证

新增 12 项回归（`detail_interaction_test.dart` 10 项，`episode_catalog_test.dart` 2 项）：

- 30 季与特别篇：自动定位当前季、按需构建、连续上下到列表尾、取消/选择一次、关闭按钮往返恢复焦点。
- 窄视口的少量季横向往返；完整简介滚动、返回焦点及静态帧；放大字体的标题与操作可达。
- 资源快捷入口露出第 26 个版本且不选源/播放；加载锚点在结果到达后保持；两种详情在选择超前集后从资源区确认播放正确服务器、正确集。
- 200 集只构建选中项附近窗口，远处未播出集仍可操作；账号替换后旧面板不能提交；详情骨架可返回且稳定后不持续调度帧。

本地测试在隔离的兼容 Flutter 副本运行，不改生产依赖；静态检查另用正式 Dart 3.13.5 与 Flutter 3.47.7 框架源码，正式 Flutter 3.47.7 的完整检查以 PR Checks 为准。真实字体的固定数据预览用于排查排版，不能视为实际海报/网络/设备性能证据。

## 实机仍需验收

尚未连接 Windows 或 Android TV。widget 测试不能证明遥控器驱动、Narrator/TalkBack、解码和实际帧率。本批没有真实 FPS 或内存改善数据。

- Windows：鼠标、滚轮、Tab、方向键和 Esc 混用；缩窗、放大字体后操作仍可见，阅读滚动不带动背景。
- Android TV：当前季/特别篇/200 集导航、快速长按、面板打开途中返回，关闭后焦点恢复；选择无资源集不误播，跨服超前集正确播放。
- 同一设备与源，冷/热缓存重复打开详情、切季、展开简介和选源，比较 build/raster、图片 pending/live 和 RSS；日志继续通过原局域网入口导出。

后续模块：播放器控制层单独实施，先覆盖输入与显隐回归，再评估 OSD 更新隔离、字幕音轨面板与进度操作；不在本批混改内核或缩略图预览。
