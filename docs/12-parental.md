# 12 家长控制 / 儿童模式

设置 → 家长控制。开启时设置 4 位家长 PIN（只保存加了设备 ID 的 SHA-256 哈希），关闭时需要输入；连续输错会逐渐变慢。

## 儿童模式做什么

| 位置 | 处理 |
| --- | --- |
| 服务器 | 「资源库 → 编辑服务器」里勾选 R18 的服务器整个隐藏：`AppConfig.servers` 只返回可见服务器，`allServers` 保留全部；保存配置、修改服务器列表、`copyWith` 默认都用全部，隐藏的服务器不会丢 |
| 媒体服务器请求 | 列表、最近添加、继续观看请求带 `MaxOfficialRating`（7 岁 → G，12 岁 → PG，16 岁 → PG-13），Emby / Jellyfin 在服务器端过滤；返回后 Viora 按分级再过滤一次（单集跟随剧集不单独过滤） |
| 本地索引 | 搜索、最近入库、TMDB 详情的媒体库匹配都经过 `itemVisible`（服务器可见 + 分级允许）；索引字段加入 OfficialRating |
| TMDB 推荐 | 首页各行换成 discover：电影按美国分级（certification.lte）且限定动画 / 家庭类，剧集限定少儿 / 动画 / 家庭类 |

分级换算见 `ratingAge`：G / TV-Y → 0，TV-Y7 → 7，PG / TV-PG → 8，PG-13 → 13，TV-14 → 14，R / TV-MA → 17，NC-17 / X / R18 → 18，
另外认识带数字的分级（FSK-16、GB-15、KR-19、JP-R18+ 等）。没有分级的内容默认放行（国内资源很多没有分级），可以在设置里改为隐藏。

## 已知限制

- 依赖服务器上的分级信息：没有分级、分级错误的内容需要在服务器上补全或用「隐藏没有分级的内容」。
- 忘记 PIN 只能清除应用数据（或重装）后重新设置。
